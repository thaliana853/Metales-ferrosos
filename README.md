# Metales ferrosos — sitio web interactivo

Proyecto académico para la asignatura de Materiales de Ingeniería, Universidad Francisco de Paula Santander.

## Archivos
- `index.html`: contenido y estructura del sitio.
- `styles.css`: diseño adaptable a celular y computador.
- `script.js`: funcionamiento de la evaluación interactiva.

## Cómo probarlo
Abre `index.html` en un navegador. No requiere instalar programas ni dependencias.

## Cómo publicarlo en GitHub Pages
1. Inicia sesión en https://github.com/
2. Crea un repositorio nuevo, por ejemplo `metales-ferrosos`.
3. Sube `index.html`, `styles.css`, `script.js` y este `README.md` a la raíz del repositorio.
4. En el repositorio, entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama **main** y la carpeta **/(root)**; pulsa **Save**.
7. Espera unos minutos. GitHub mostrará la dirección pública de la página en la sección Pages.

## Personalización
Puedes editar los nombres de los integrantes y el curso directamente en `index.html` si el profesor exige que aparezcan en la portada. El contenido se elaboró como material educativo general y puede complementarse con las referencias bibliográficas solicitadas por el docente.
